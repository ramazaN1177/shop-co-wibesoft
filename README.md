# SHOP.CO - Modern E-Commerce Platform

SHOP.CO is a premium, responsive e-commerce application built with the latest web technologies. It features a seamless shopping experience with dynamic product filtering, persistent cart management, and a polished UI/UX designed for all devices.

## 🚀 Key Features

- **Dynamic Product Filtering:** Advanced category, price range, color, and size filters on the Category Page.
- **Persistent Cart Management:** Centralized state management using **Zustand** with `localStorage` persistence.
- **Detailed Product Pages:** Interactive color/size selectors and quantity management.
- **Mobile Responsive:** Fully optimized "Mobile-First" design with a custom bottom-drawer filter system for smaller screens.
- **High Performance:** Built with **Next.js 15** (App Router) for optimal speed and SEO.
- **Modern UI:** Styled with **Tailwind CSS**, featuring custom fonts (Integral CF & Satoshi) and smooth animations.

## 🛠 Tech Stack

- **Framework:** [Next.js 15+](https://nextjs.org/)
- **State Management:** [Zustand](https://github.com/pmndrs/zustand)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Deployment:** [Vercel](https://vercel.com/)

## 🏁 Getting Started

### Prerequisites
- Node.js 18+ 
- npm / yarn / pnpm

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/ramazaN1177/shop-co-wibesoft.git
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
